## Port

The web app is a TanStack Start SPA served by Vite's preview server on port **3002**, matching `server.port` in `apps/web/vite.config.ts` and the `port` value in the web Helm chart. Make sure the web Dockerfile builds the app and starts the preview server on that port:

```Dockerfile apps/web/Dockerfile
EXPOSE 3002

CMD ["pnpm", "--filter=web", "start"]
```
